# Домашнє завдання: багатопотоковість та асинхронність

Курс: **Системне програмування**  
Тема: **Багатопотоковість та асинхронність**  
Модуль 3. Частина 2

## Опис

Проєкт реалізовано як один Windows Forms застосунок на C#. Усі п'ять завдань знаходяться в одному вікні на окремих вкладках.

## Реалізовані завдання

1. **Танцюючі прогрес-бари**  
   Користувач задає кількість прогрес-барів. Після натискання кнопки кожен прогрес-бар заповнюється у власному потоці, а швидкість і колір визначаються випадково.

2. **Емуляція кінних перегонів**  
   У гонці беруть участь п'ять коней. Кожен кінь відображений окремим прогрес-баром і рухається у власному потоці. Після завершення показується таблиця результатів.

3. **Числа Фібоначчі**  
   Користувач вводить верхню межу, а програма асинхронно обчислює всі числа Фібоначчі від 0 до цієї межі.

4. **Пошук слова у файлі**  
   Користувач задає слово та шлях до файлу. Пошук виконується асинхронно, після чого показується кількість входжень слова.

5. **Пошук слова у директорії**  
   Користувач задає слово та шлях до директорії. Програма асинхронно обходить усі піддиректорії та формує звіт для файлів, де знайдено слово.

## Запуск

Потрібен .NET SDK 8 або новіший на Windows.

```bash
dotnet run
```

## Примітка

Пошук слова виконується без урахування регістру та рахує окремі слова, а не частини інших слів.
